Move around

h j k lMove. Arrows work too. l or Enter opens the folder or file, h goes up one level
ghJump to ~
zhShow or hide hidden files (.git, .env)
zpShow or hide the preview column
iSelected file full screen, read-only — for long markdown. q comes back

Create

:touch:touch notas.md — new empty file in the current folder
:mkdir:mkdir borradores — new folder
:edit:edit notas.md — new file opened straight in nano; it is created when you save

Edit

EEdit the selected file in nano — Ctrl+O saves, Ctrl+X returns to ranger
cwRename

Enter on a text file ends up in nano too, but ranger picks the program by file type, so E is the predictable choice. Change it by setting EDITOR in ~/.zshrc.local.

Copy, move, delete

yyCopy the selected (or marked) files
ddCut. It does not delete — it prepares the files to be moved
ppPaste what was copied or cut, into the folder you are in
dDDelete. Asks y/n. No trash: it is gone. On a folder, everything inside goes with it

Several files at once

SpaceMark the file under the cursor — repeat on each one, then yy, dd or dD act on all of them
vMark every file in the folder
uvClear all marks

Search

//text — search by name in the current folder. n next match, N previous
fThen type — jumps to the first file that matches as you type

Shell & misc

SOpen a shell in the current folder. exit returns to ranger
!Then a command — run one shell command here, without leaving ranger
Ctrl+RReset and redraw if the screen gets garbled
qQuit

tree — the static half

ranger walks the hierarchy; tree prints it, for pasting a repo layout into a README or a commit message. Both are installed by install.sh on Fedora and Debian/Ubuntu; on Windows they live in WSL.

tree -L 2 -I .git # two levels deep, skip .git tree -d -I .git # directories only tree -a -I .git # include dotfiles

Without -I .git the .git internals flood the output; -L is what keeps it readable in big repos. The last line is the count — 11 directories, 17 files.
