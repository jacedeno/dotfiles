Move around

h j k lMove. Arrows work too. l enters a folder, h goes up one level
gg GTop / bottom of the list
ghJump to ~
.Show or hide hidden files (.git, .env)
J KScroll the preview down / up — for long markdown

Create, open, rename

aCreate. notas.md makes a file, borradores/ (trailing slash) a folder
EnterOpen. Text files go to $EDITOR (nano) — Ctrl+O saves, Ctrl+X returns to yazi
rRename. With several files selected, renames them all at once in the editor

Copy, move, delete

yCopy the selected (or hovered) files
xCut. It does not delete — it prepares the files to be moved
pPaste into the folder you are in. P overwrites existing files
dMove to the trash. Asks to confirm. gt browses the trash
DDelete permanently. No trash: it is gone. On a folder, everything inside goes with it

Several files at once

SpaceSelect the file under the cursor and move down — then y, x or d act on all of them
Ctrl+ASelect every file in the folder
vVisual mode — move the cursor to select a range
EscClear the selection

Search

/Find by name in the current folder. n next match, N previous
fFilter the list as you type
SSearch file contents below here (ripgrep)
zJump anywhere below here with fzf

s (recursive name search) needs fd and Z needs zoxide — neither is installed.

Shell & misc

;Then a command — run one shell command here, without leaving yazi
Ctrl+ZSuspend yazi to the shell. fg brings it back
ccCopy the file's full path to the clipboard
~Help — every key, searchable
qQuit

tree — the static half

yazi walks the hierarchy; tree prints it, for pasting a repo layout into a README or a commit message. Both are installed by install.sh on Fedora and Debian/Ubuntu; on Windows they live in WSL.

tree -L 2 -I .git # two levels deep, skip .git tree -d -I .git # directories only tree -a -I .git # include dotfiles

Without -I .git the .git internals flood the output; -L is what keeps it readable in big repos. The last line is the count — 11 directories, 17 files.
